# Railway Photo Project RTM 67

เว็บไซต์นำเสนอโครงงาน “การออกแบบและพัฒนาเว็บไซต์กิจกรรมประกวดภาพถ่าย เพื่อส่งเสริมการท่องเที่ยวทางรถไฟ”

## เว็บไซต์ที่เกี่ยวข้อง

- เว็บไซต์นำเสนอโครงงาน: https://railway-photo-project-rtm67.prungpiam1978.chatgpt.site
- เว็บไซต์ประกวดภาพถ่าย Thai Rail Shot: https://thairailshot.railway67.workers.dev/

## การเปิดเว็บไซต์

เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ หรือเผยแพร่ผ่าน GitHub Pages

## เนื้อหาหลัก

- ที่มา ปัญหา และวัตถุประสงค์จากรายงาน
- แนวคิดการท่องเที่ยวทางรถไฟและการสื่อสารด้วยภาพ
- รูปแบบกิจกรรม กติกา และขั้นตอนระบบ
- ความปลอดภัย ลิขสิทธิ์ และการคุ้มครองข้อมูลส่วนบุคคล
- เกณฑ์ตัดสิน งบประมาณ แผนดำเนินงาน และ SWOT
- คู่มือเข้าใช้งานและรายการตรวจสอบก่อนส่งผลงาน
- แนวปฏิบัติก่อน–ระหว่าง–หลังทำกิจกรรม และขั้นตอนเมื่อพบปัญหา
- กรอบ Input–Process–Output–Outcome, หลัก POLC และทะเบียนความเสี่ยง
- ตัวชี้วัด ค่าเป้าหมาย ข้อจำกัด และแนวทางต่อยอด
- เชื่อมต่อเว็บไซต์ Thai Rail Shot เพื่อชมผลงานของผู้ใช้งาน
